# Zoderise 3D Map

Developer: Zubair Zahidi  
School: Kardan Private School  
Company: Zoderise  
CEO: Zubair Zahidi

The portable Windows x64 application is built into `release/Zoderise-3D-Map-1.0.0-x64.exe`. Send that file to recipients; Node.js, an editor, and npm are not needed to use it. Internet access is required for online maps and live data. Optional providers require recipients' own API keys through POWER UP. Settings are stored in the user's application-data directory. This build is unsigned, so Windows may show a publisher warning.

To rebuild from the repository root: install dependencies in the root and desktop directories, then run `npm run desktop:build`.

The original application's MIT license and copyright attribution are included. The 3D application and providers retain their existing implementation. Local branding backups and generated test files are excluded from the published repository.
