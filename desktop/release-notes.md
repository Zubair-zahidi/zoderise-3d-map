# Zoderise 3D Map 1.0.0

![Zoderise 3D Map](https://raw.githubusercontent.com/Zubair-zahidi/zoderise-3d-map/main/docs/images/banner.svg)

Portable Windows x64 application by Zoderise. Developer and CEO: Zubair Zahidi. School: Kardan Private School.

Download the .exe below and double-click it. No Node.js, editor or developer platform is required. Internet access is needed for online maps and feeds.

## Start exploring

1. Download **Zoderise-3D-Map-1.0.0-x64.exe** from the assets below.
2. Open it and choose **Explore manually**.
3. Use **Reset Globe** for a full-Earth view; scroll or pinch to zoom.
4. Open **POWER UP** to add your own optional provider keys.

## Included in this release

- Maximized desktop viewport at 100% interface scale.
- Original 3D map and camera behavior preserved.
- Scroll and touchpad pinch event checks passed.
- No bundled personal API keys. Configure your own providers through POWER UP.
- Keyless map imagery is available at startup.
