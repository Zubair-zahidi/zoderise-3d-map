# Screenshot and artwork provenance

The PNG files in this directory are actual Zoderise 3D Map desktop captures using keyless imagery. No personal API keys are configured or shown. Map-provider attribution remains visible in the images.

- `globe.png`: full-Earth exploration view.
- `thermal.png`: FLIR visual style.
- `surveillance.png`: NVG visual style.
- `retro.png`: retro display style.
- `anime.png`: illustrated display style.
- `noir.png`: monochrome display style.
- `providers.png`: the POWER UP provider-settings panel with empty credential fields.

The display styles apply visual effects to map imagery; they are not actual thermal or night-vision observations. The SVG banner is native vector artwork for the Zoderise repository presentation.

The map and third-party data retain their original attribution and applicable terms; see [DATA_SOURCES.md](../../DATA_SOURCES.md) and [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md). The upstream media in `docs/media/` have separate provenance notes.
